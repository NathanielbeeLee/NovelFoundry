# Support

NovelFoundry is an actively developed open-source project. Start with the
documentation before opening a request:

1. Read the [installation guide](docs/public/installation.md).
2. Check the [FAQ](docs/public/faq.md).
3. Follow the [troubleshooting guide](docs/public/troubleshooting.md).
4. Review the [recovery playbook](docs/public/playbook/recovery-by-phase.md)
   when a long-running task is paused or incomplete.

## Questions and feature requests

After the independent public repository is published, use GitHub Discussions
for usage questions and the feature request template for product proposals.
Use the bug report template for reproducible defects. Include the operating
system, application version or commit, provider type, relevant task stage, and
sanitized logs. Never include API keys, private novels, personal data, or
unredacted model responses.

## Security reports

Do not use public issues for vulnerabilities. Follow [SECURITY.md](SECURITY.md)
for the private reporting path.

## Scope

Support is best effort. The project does not promise that every model provider,
custom endpoint, plugin, or generated result will behave identically. Provider
limits, model behavior, and local hardware can affect long-running workflows.
