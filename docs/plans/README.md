# Active Plans

This directory contains only plans that still guide a current implementation
phase. Durable rules belong in `docs/wiki/`; user-facing outcomes belong in
release notes. Completed plans should be reduced to durable decisions;
superseded plans with recovery value belong in local maintainer archives.

## Current plan

- [NovelFoundry optimization backlog](./optimization-backlog.md)

Completed or superseded plans are removed from the maintained documentation
tree. Consult maintainer archives when older evidence is required; no
historical plan is a current implementation instruction.
