# Source and License Notes

NovelFoundry is a distinct product built on an existing code history. Its name,
direction, and new features do not remove copyright or license obligations for
code already present in that history. The repository's [NOTICE](../../../NOTICE)
retains the original attribution; [LICENSE](../../../LICENSE) contains the
AGPL-3.0-only terms that apply to this distribution.

## Current rule

- Keep copyright and license notices attached to existing code and assets.
- Contributions must be submitted by people who can license them under
  AGPL-3.0-only; the contribution policy does not grant rights over code the
  contributor does not own.
- A similar feature or design idea does not, by itself, establish that code was
  copied. Check file-level evidence and attribution before making a source claim.
  Public history starts at the publication snapshot; maintainers retain the
  earlier history in local archives for provenance and recovery. Rebuilding
  history does not establish independent authorship or change license terms.
- Before publishing a new repository or distributing packages, review copied
  code, prompts, images, data, and design assets at file level for attribution
  and license obligations. This review remains incomplete.

When the origin or rights for a file are unclear, record that uncertainty and
resolve it before representing the file as independently owned or relicensable.
