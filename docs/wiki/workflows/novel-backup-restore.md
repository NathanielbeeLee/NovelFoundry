# Novel Backup and Restore

A portable novel backup captures the book, chapters, planning, characters, world, linked references, and visual assets needed to restore an independent copy. It does not resume an old worker command or copy private runtime leases.

Create and verify a backup before destructive edits or polish rollback. Import performs version, size, and integrity checks and keeps the original project unchanged.

## Desktop identity and data continuity

NovelFoundry stores desktop data under its own application directory. Existing
desktop data remains in the prior directory until the user chooses to import
it. The maintenance panel may suggest a compatible prior SQLite database; it
never imports or deletes that database automatically. Database import creates
and verifies a backup of the current destination before replacement and
requires the previous app to be closed. Generated images and other external
files require the portable novel backup and restore path. The two import paths
have different scopes and must not be described as a complete automatic
migration.
