# First Novel Walkthrough

This walkthrough moves from an empty project to a confirmed direction and a
readable first chapter.

## Path overview

| Step | User action | Main artifact |
| --- | --- | --- |
| 1 | Configure a model | Provider and route settings |
| 2 | Enter an idea | Director task |
| 3 | Generate and compare directions | Candidate batch |
| 4 | Confirm a direction and title | Candidate and title pack |
| 5 | Create the novel | Novel project |
| 6 | Prepare the book | Contract, story macro, world, and cast |
| 7 | Prepare volumes and chapter tasks | Volume plan, beat sheet, chapter tasks |
| 8 | Choose guided or professional production | Chapter runtime and workspace handoff |
| 9 | Read the saved first chapter | Prose, review, repair record, and export |

## 1. Configure a model

Open Settings and configure one model. Confirm the API key, base URL, and
structured output test. A single stable model is enough for the first run.

## 2. Enter one idea

Open Getting Started or Creative Hub and describe the idea in one or two
sentences. Let the director ask focused questions and produce clear, different
directions.

## 3. Choose a direction

Compare each candidate's reader promise, conflict, title group, and reason to
choose. Confirm one direction. The confirmation creates the novel and a
resumable director task.

## 4. Let the director prepare the book

The director prepares framing, the book contract, story macro plan, world,
characters, volume strategy, pacing, and chapter tasks. Use Director
Follow-ups or Task Center when a stage pauses.

## 5. Choose a production mode

Choose guided creation when you want AI to continue through the book with a
simple chapter shelf. Choose the professional workspace when you want to
inspect and edit planning and chapter content.

## 6. Generate and review chapter one

The shared chapter runtime assembles scoped context, generates prose, reviews
it, repairs local issues when needed, and finalizes continuity state. Open the
saved chapter only after the task reports a stable result.

## If the path pauses

Read the checkpoint reason before retrying. Fix provider or quota issues,
confirm a candidate, add missing book information, or use the recovery action.
Do not create a second novel to bypass a recoverable pause.
