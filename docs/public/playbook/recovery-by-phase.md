# Recovery by Phase

Use this guide when a director or chapter task pauses. A visible pause often
means a checkpoint or approval request rather than a failure.

## Checkpoint or failure?

- Waiting for direction means choose a candidate.
- Waiting for cast confirmation means review the proposed characters.
- Volume or chapter readiness means approve or inspect the plan.
- Waiting for replan means review the quality or structural reason.
- Failed means read the Task Center error and determine whether a retry is safe.

Do not delete or recreate a project before checking Director Follow-ups.

## Recovery matrix

| Phase | First place to look | Usual action | Replan when |
| --- | --- | --- | --- |
| Idea alignment | Creative Hub and Task Center | Clarify the premise or change model | The project has not been created; continue candidate work |
| Direction batch | Direction page | Generate another batch or revise a candidate | The core promise is wrong |
| Title pack | Direction page | Regenerate titles only | Rarely |
| Novel creation | Task Center | Retry candidate confirmation | A data conflict cannot be repaired |
| Story macro | Novel workspace and Follow-ups | Adjust the macro or return to the direction | The central hook changed |
| Book contract | Book framing | Edit the contract and continue | It changes every volume plan |
| World setup | World workspace | Repair or regenerate world rules | The main conflict depends on new rules |
| Character setup | Cast page | Confirm, merge, or regenerate characters | Character goals change the main plot |
| Volume strategy | Volume workspace | Regenerate strategy or adjust the contract | The first-volume promise is wrong |
| Beat sheet or chapter list | Planning workspace | Regenerate the affected structure | The volume strategy itself is wrong |
| Chapter synchronization | Task Center | Retry synchronization | Rarely |
| Chapter detail | Follow-ups and Task Center | Continue from the latest chapter | The chapter list is incorrect |
| Chapter execution | Chapter page and Task Center | Retry, change model, or inspect context | The task conflicts with the book plan |
| Review and repair | Chapter page | Light repair, record quality debt, continue | The runtime explicitly requests replan |

## Stale commands

A worker lease can become stale after a process restart or lost heartbeat. Use
the Task Center recovery action so the runtime can re-establish a lease. Do not
start a duplicate command from another page.

## Data safety

Before deleting data, resetting a database, or migrating manually, create and
verify a backup. Preserve usable chapter text even when a review or asset
synchronization fails.
