# Public Roadmap

This roadmap is for users and people following the project's direction. It
separates shipped work, active work, and ideas under evaluation. The complete
history is in [Release notes](#/docs/release-notes).

## Shipped recently

Recent releases have delivered:

- Public documentation navigation, search, playbooks, director stages, chapter
  execution, retrieval, and recovery guides.
- Adjustable embedding and vector-store concurrency, streaming indexing, file
  preview, and virtualized browsing.
- Character appearance extraction with review before profile and image updates.
- Book-analysis profiles, evidence traceability, budgets, release isolation,
  and structured retrieval.
- Character resource ledgers, image-generation confirmation, and director pause
  notifications.
- Comic workspace consistency improvements for scenes, character assets, and
  appearance anchors.

## In progress

### Chapter editor v2

Bring prose, review issues, repair results, and quality debt into one chapter
entry point so authors move less between Chapter pages and Task Center.

### Director execution boundaries

Move takeover, continuation, recovery, and replan actions through one pipeline
engine with explicit input, output, progress, and recovery contracts.

### Prompt Workbench and step runtime

Consolidate product prompts into editable, versioned assets that can be bound
to director steps while keeping structured output contracts visible.

### Character resource system

Extend character cards with action boundaries, narrative roles, relationship
tension, and chapter-scoped resource context.

### Chapter production pipeline

Make generation, review, repair, state feedback, and post-processing easier to
observe and recover.

### Derivative workspaces

Continue comic and short-drama production toward publishable visual and script
outputs while keeping the novel completion path as the source of truth.

### Creative Hub runtime

Continue the staged migration toward a graph-backed runtime without creating a
second task state machine or losing existing recovery behavior.

## Under evaluation

- Long-range context memory that remains reliable after dozens of chapters.
- Cross-book reuse of genres, progression modes, worlds, characters, and style
  assets with clear provenance.
- A narrative editor that makes world, character, event, and chapter state
  observable without requiring beginners to maintain game-like data tables.
- Multi-world and IP-universe assets with explicit canon and branch boundaries.
- Simpler desktop setup and self-service recovery for providers and local data.
- Quantitative book-level quality reporting.
- Research-friendly open-source instrumentation for long-running AI workflows.

These ideas are not commitments. The near-term priority remains a stable
beginner path, reliable director recovery, chapter quality, and long-form
continuity.

## Maintenance rule

When a user-visible release ships, add it to Release Notes and update the
shipped section here. Move paused work to evaluation or remove it; do not keep
an outdated implementation plan in the public roadmap.
