# Knowledge Base

Knowledge Base stores reference documents, settings, book-analysis results, and searchable material for later planning and writing.

## Lifecycle

1. Add or upload a document.
2. Confirm its source and scope.
3. Wait for indexing to finish.
4. Test retrieval or associate it with a project.
5. Review the index status when recall misses a document.

Uploaded text does not automatically override established book facts. Keep private novels, keys, and sensitive references out of public issue reports.
