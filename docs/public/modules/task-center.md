# Task Center

Task Center shows queued, running, completed, failed, and recoverable work. It is the operational inbox for long-running director and chapter tasks.

## Use it for

- Checking the current action and progress.
- Reading a failure reason before retrying.
- Resuming, cancelling, or archiving a task when the action is available.
- Confirming whether a background task is still running before starting another one.

A task view is a projection of runtime state. Do not infer failure from one page alone; compare it with Director Follow-ups and the novel workspace.
