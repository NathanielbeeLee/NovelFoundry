# Home

Home is the recommended starting point after setup. It summarizes the next creation action, active projects, task reminders, and asset health.

## What to do here

- Continue the recommended action for the current novel.
- Open Getting Started when the first-novel path is incomplete.
- Inspect task and asset reminders before starting another long operation.

Home is a projection of project state. Use the novel workspace or Task Center for editing and recovery actions.
