# Release Notes

This file keeps the complete maintained user-facing update history. The README
shows only the newest date. Earlier entries without public summaries are indexed
below; their source evidence is retained in local maintainer archives.

## History

### 2026-10-01

- The workspace loads editing, graph, and Markdown tools when their pages need
  them, reducing the compressed JavaScript required at startup by about 30%.
- Prompt Workbench lists comic visual-fact extraction so you can inspect the
  instructions that help keep characters, places, props, and states consistent
  across episodes.

### 2026-09-30

- NovelFoundry's source is available in its own public repository, with
  installation instructions and contributor documentation.
- Use `main` to clone the project or contribute changes; it is the default
  development branch.
- Explore creation modes, model options, and export tools through a focused
  quick start, feature highlights, and NovelFoundry artwork.
- Existing local settings, portable novel backups, and earlier desktop data
  remain readable while NovelFoundry uses its own configuration names.
- First-run setup prepares local storage before applying the project structure.

### 2026-09-28

- Chapter drafts now favor scene-specific action and character voice over
  repetitive phrasing and generic conclusions.
- Writing review checks the whole passage in context, so a chapter can be
  flagged for repeated formulaic prose even when it contains no stock phrases.
  Edits keep established events, uncertainty, and intentional style intact.
- Whole-book review can point out repeated chapter openings, endings, and
  character reactions when the supplied chapters show the same pattern.
- When a chapter needs to touch an older foreshadowing thread, writing context
  also searches using that thread's title to help recover its earlier setup.

### 2026-09-26

- The director's initial novel settings now explain platform, audience,
  perspective, pace, length, and optional reader details in English or Chinese.
- When the final chapter is saved but its writing task fails or is cancelled,
  the director now shows a recovery step instead of saying the whole book is
  complete.
- The AI Creation Studio now shows its idea, direction, length, platform, and
  reference-writing steps in English or Chinese when you switch languages.
  Story content generated by AI remains in the language returned by your model.
- The Windows desktop app now presents itself as NovelFoundry and keeps its
  data separate. You can choose to import a previous local database after
  closing the older app; the current database is backed up first.
- Project documentation and the website now present NovelFoundry under its own
  identity, with a clear AGPL license and contribution path.
- The app shows a GitHub link when the public NovelFoundry repository URL is
  configured.

### 2026-09-24

- The README now provides a complete user, contributor, provenance, security,
  and public-project entry path.
- Public documentation and repository checks now describe a reproducible first
  run, contribution workflow, support boundary, and current publication status.
- Site and desktop release configuration no longer hard-code the original
  repository; future public coordinates are supplied by the deployment
  environment.
- The project is now presented as NovelFoundry, an independent long-form fiction production system.
- The application shell, mobile navigation, and the first onboarding route include a persistent Chinese/English language switch.
- Novel-edit localization assets now have an explicit catalog boundary, and the route's static onboarding states use that catalog.
- The public README, introduction, contribution guide, CLA, security policy, and code of conduct now provide an English contributor path.
- Architecture and provenance records now explain ownership, refactoring order, and the relationship to the original project.
- The repository documents the beginner path to a first readable chapter and the preparation work for independent publication.
- Maintained public guides, architecture notes, and contribution references now
  use English, while superseded non-maintained documents were removed from the tree.
- Home and first-run panels now use the same translation catalog for loading,
  errors, creation actions, project facts, and attention states.
- Shared selectors, model configuration, streamed output, fullscreen controls,
  and local service startup states now follow the selected language.
- Reusable task summaries, recommended-next-step panels, and consequence
  messages now follow the selected language in deeper workspaces as well.
- Shared asset navigation, asset status cards, project navigation, and
  automatic-approval risk labels now follow the selected language.
- Automatic director strategy and approval preference panels now use the
  selected language for their actions, explanations, and accessibility labels.
- Knowledge binding and document selection controls now use the selected
  language for source types, retrieval mode, loading states, and summaries.
- Visual asset selection, details, accessibility labels, and localized dates
  now follow the selected language.
- A focused CI workflow checks the documentation manifest and workspace type
  contracts for pushes and pull requests.
