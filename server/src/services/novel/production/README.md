# Novel Production Boundary

Novel production is the single path for chapter generation, review, repair,
finalization, and post-chapter synchronization. Manual actions, batches, and
AI director continuation may use different transports but must converge on the
same runtime facade.

The runtime preserves usable prose, records quality debt for local issues, and
only blocks globally for explicit replan, unusable output, or runtime/data
safety failure. New production behavior belongs in the runtime modules and
registered prompts, not in route-specific helpers.
