# Onboarding Module

The onboarding module computes the first-novel journey from real provider,
director, novel, and chapter state. It returns one recommended next action and
milestones without allowing browser storage to fabricate completion.

The first milestone ends at a readable first chapter with review and continuity
state. Quick setup checks normal and structured model output before permitting
AI writes. Optional retrieval, style, image, and detailed routing settings do
not block that path.
